# «Рядом» для инвесторов

Статический сайт без сборки: открывается как есть на GitHub Pages или Vercel.

| Файл | Что там |
|---|---|
| index.html | Страница для инвесторов: рынок с источниками, тезисы, продукт, модель заработка, финансовый калькулятор со сценариями, раунд и план, риски, форма связи |
| styles.css, common.js | Дизайн, шапка и подвал сервиса «Рядом» (ссылки ведут на основной сайт) |
| analytics-data.js | Данные рынка с первоисточниками (общие с разделом «Аналитика») |
| psychologists-data.js, articles.js | Каталог психологов и журнал — для счётчиков продукта и формы записи |

Основной сайт: https://aperevedencev-glitch.github.io/ryadom/

## Форма → Supabase
Заявки инвесторов сохраняются в таблицу `investor_requests` (проект wuvadreohiphwevprwmk).
Публичный ключ даёт только INSERT (RLS), читать данные с сайта нельзя. Смотреть заявки: Supabase → Table Editor.

## Публикация на GitHub Pages
Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

Финансовая модель, план и распределение средств на странице — иллюстрация для обсуждения, а не прогноз или оферта.
